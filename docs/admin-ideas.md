# Идеи и планы по улучшению админки (`/admin`)

Список небольших практичных улучшений для удобства ежедневной работы. Не обязательны к немедленной реализации — брать по мере необходимости.

## 1. Порядок скриншотов в редакторе (`←` / `→`)

- **Сейчас:** в `frontend/components/dashboard/project-images.jsx` картинку можно только сделать обложкой (`makeCover`), но нельзя поменять местами 2-й, 3-й и последующие скриншоты.
- **Что сделать:** добавить кнопки перемещения влево/вправо на карточках сохранённых скриншотов.
- **Объём:** только фронтенд — `edit_pictures` в `backend/core/views.py` уже сохраняет порядок по массиву `pictures`.

## 2. Быстрое «Опубликовать / В черновик» из списка проектов

- **Сейчас:** чтобы временно скрыть или опубликовать проект, нужно открыть редактор, переключить чекбокс и сохранить форму.
- **Что сделать:** добавить переключатель статуса публикации прямо в строку списка `frontend/components/dashboard/project-list-item.jsx` (и минимальный endpoint или обновление поля на бэкенде).

## 3. Сохранение по `Cmd+S` / `Ctrl+S` в редакторе

- **Сейчас:** в `frontend/components/dashboard/project-form.jsx` нажатие `Cmd+S` / `Ctrl+S` вызывает системное сохранение HTML-страницы браузера.
- **Что сделать:** перехватывать `Cmd/Ctrl+S` при открытом редакторе и отправлять форму сохранения (с учётом текущей валидации и состояния `saving`).

## 4. Превью `DE / EN` и подсказка о незаполненном переводе

- **Сейчас:** карточка предпросмотра (`frontend/components/dashboard/project-preview.jsx`) показывает только немецкий текст, хотя рядом заполняется английская версия.
- **Что сделать:** добавить переключатель `DE / EN` на карточке превью (включая отображение английского срока разработки через `englishTime`) и лёгкую подсказку, если у опубликованного проекта не заполнен английский перевод.

## 5. Удобства в заявках: копирование контакта в 1 клик и экспорт в CSV

- **Сейчас:** в `frontend/components/dashboard/lead-card.jsx` email и телефон — ссылки `mailto:` / `tel:`, которые на компьютере часто открывают почтовый клиент вместо копирования.
- **Что сделать:**
  - добавить кнопку копирования рядом с email и телефоном;
  - добавить кнопку «Экспорт CSV» на вкладке «Заявки» для выгрузки текущего отфильтрованного списка (реализуется на клиенте без изменений на бэкенде).
